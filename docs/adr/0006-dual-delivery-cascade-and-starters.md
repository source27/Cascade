# 双交付物：Cascade 能力库 + 可 fork Starter

Cascade 定位为可组合的 UPM **能力库**（默认可替换 Bootstrap 骨架，不绑定玩法）；开新项目的生产起点是 monorepo 内的 **Starter**（`Starters/Mobile`、`Starters/Indie`），不是演示用 Example。库通过文档说明如何组装；Starter 是组装结果的薄壳模板。受众以作者自用为主（公司手游 + 个人独立游戏）。

**Considered options：** 仅库+薄 Example（与「开项目直接落地」相反）；仅 Starter、不维护纯库用法（失去可组装叙事与集成包边界）。
